Funktionsweise

How it works

Der Kill-Switch-Dienst schreibt seinen Zustand in eine Statusdatei und meldet jede Änderung über eine Systemkennung. Dieser Tweak läuft in SpringBoard, horcht auf diese Meldung und blendet das Symbol ein. Ein langsamer Sicherheitstakt fängt ab, falls eine Meldung verlorengeht.

The kill switch daemon writes its state to a status file and posts a system notification on every change. This tweak runs inside SpringBoard, listens for that notification and shows the icon. A slow fallback timer covers the case of a missed notification.

Ein Symbol in der Statusleiste lässt sich nur aus SpringBoard heraus anzeigen — deshalb ein eigener Tweak statt einer Funktion der App.

A status bar icon can only be drawn from within SpringBoard, hence a separate tweak rather than a feature of the app.
